# Enterprise Knowledge System

A portfolio project for building a permission-aware enterprise knowledge
system. The application will let employees securely find internal knowledge
while enforcing role-based access to sensitive documents.

## Current status

The FastAPI and MongoDB backend foundation is ready. It includes a MongoDB
startup health check and a `GET /health` endpoint.

## Project structure

```text
backend/   Python, FastAPI, and MongoDB API
frontend/  Future web interface
```

See the [backend README](backend/README.md) for setup and local run
instructions.
